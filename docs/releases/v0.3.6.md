# Womprat v0.3.6

Outbound hostname lookups use the embedded Tailscale DNS resolver across browser SOCKS traffic, SSH, VNC, RDP and managed downloads. Resolved addresses are dialled through `tsnet`.

## Known limitation

This version's Tailscale v1.82.5 dependency does not honour custom nameservers' **Use with exit node** policy. Its upstream DNS forwarding can also use host-network sockets. Use v0.4.0 or later for policy-aware, tailnet-only upstream queries.
