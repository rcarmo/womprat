# Womprat v0.3.6

Womprat now resolves outbound hostnames through its embedded Tailscale DNS resolver. This covers configured custom nameservers and split-DNS routes, as well as MagicDNS. The resulting IP is dialled through `tsnet`, retaining the current tailnet, subnet and exit-node routing policy. Failed DNS queries do not fall back to the host OS resolver. Browser SOCKS traffic, SSH, VNC, RDP and managed downloads share the corrected dial path.
