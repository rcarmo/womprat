# Womprat v0.2.0

Browser tabs now use separate native WebView2 views within the Womprat window. Each tab retains its page, history and scroll position; closing it leaves other tabs and SSH sessions running.

## Changes

- Page titles and favicons appear in browser tabs.
- Browser shortcuts work when focus is in either the shell or a page.
- SSH sessions survive tab switches, and password prompts support backspace.
- Browser traffic uses the embedded Tailscale SOCKS5 proxy. The exit-node picker lists peers that advertise exit-node capability.
- Browser placement and resizing account for display scaling; terminals refit to their viewport.
- Dark window chrome, a dark startup surface and an overlay terminal scrollbar improve visual consistency.
- Settings can enable optional runtime logging; it is off by default.
