# Womprat v0.4.2

Maintenance release with portable build paths and improved automated testing.

- Keeps build output and temporary files separate from source files.
- Adds CPU and memory profiling to regression tests and reduces test memory use.

Browsing, downloads, saved settings and tailnet routing are unchanged. Includes the download-cookie crash fix from v0.4.1.

Windows ARM64 and Windows x64 binaries are available with SHA-256 checksums.
