# Womprat v0.4.0

Womprat v0.4.0 adds policy-aware tailnet DNS, copyable lookup diagnostics and a removable Recent grid.

## DNS

- Tailscale v1.94.2 honours **Use with exit node** for custom and split-DNS nameservers. This allows a restricted `local` rule to use mdnsbridge while an exit node is selected.
- Supported upstream queries and application TCP connections use the embedded Tailscale stack without host-network fallback. MagicDNS and extra address records are answered locally from Tailscale state.
- Settings has a hostname lookup form with readable A/AAAA results, the matching DNS rule, nameserver eligibility, selected resolver, transport, route and timing. **Copy results** copies a text report; JSON is available under **Technical details**.
- DNS policy inspection is read-only. The app does not change tailnet-wide nameserver settings.

## Interface

- Home shows up to 10 recent items in a responsive grid.
- Each card has a remove control. Dismissals persist without closing active tabs or changing session restore.
- DNS form labels and buttons align at wide and narrow window sizes.
- Navigation error-bar controls receive clicks correctly.

## Compatibility

Windows ARM64 and Windows x64 are supported. Building from source requires Go 1.25.5 or later.

Upstream DNS currently supports TCP to IP-addressed nameservers and HTTP DNS messages to an IP-addressed exit-node PeerAPI. HTTPS/hostname upstreams and automatic retries across alternate nameservers are not implemented. Link-local IPv6 answers (`fe80::/10`) cannot be reached across the tailnet. RDP server certificate verification remains disabled.

See the [DNS guide](https://github.com/rcarmo/womprat/blob/v0.4.0/docs/dns-exit-node.md) for setup and troubleshooting.
