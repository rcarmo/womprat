# Womprat v0.4.3

Adds **Proceed anyway** to the HTTPS certificate-error banner.

- Allows explicit approval of an untrusted, expired or hostname-mismatched certificate. Approval applies to that hostname and certificate for the current browser session, including other tabs. Restart Womprat to clear exceptions.
- Keeps certificate validation enabled by default. Revoked certificates, client-certificate errors and unrelated connection failures cannot be bypassed with this button.
- Upgrades Go to 1.27.3, Tailscale to 1.104.1, and updates dependencies.
- Reduces memory allocation when serving the built-in browser interface and assets.

Windows ARM64 and Windows x64 binaries are available with SHA-256 checksums.
