# Womprat v0.4.5

Adds address-bar history suggestions and fixes tab-strip flashing during navigation.

- Suggests previous addresses and searches while typing. Use ↑/↓ and Enter, or click a suggestion; Escape dismisses the list.
- Saves up to 100 submitted inputs in encrypted local settings so history is available after restarting. Suggestions are generated locally, without contacting a search provider.
- Keeps tab elements and inactive icons in place when navigation starts or finishes, avoiding a full tab-strip rebuild.

DuckDuckGo/Bing/Google search settings, direct URLs and SSH/VNC/RDP handling are unchanged. Public browsing still requires a working exit node.

Windows ARM64 and Windows x64 binaries are available with SHA-256 checksums.
