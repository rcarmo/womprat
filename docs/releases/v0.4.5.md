# Womprat v0.4.5

Adds address-bar history suggestions and fixes tab-strip flashing during navigation.

- Suggests previous addresses and searches while typing. Use ↑/↓ and Enter, or click a suggestion; Escape dismisses the list.
- Saves up to 100 submitted inputs in encrypted local settings so history is available after restarting. Suggestions are generated locally, without contacting a search provider.
- Keeps tab elements and inactive icons in place when navigation starts or finishes, avoiding a full tab-strip rebuild.

DuckDuckGo/Bing/Google search settings, direct URLs and SSH/VNC/RDP handling are unchanged. Public browsing still requires a working exit node.

Windows ARM64, Windows x64 and Linux x86-64 AppImage downloads are available with SHA-256 checksums. The Linux build uses GTK/WebKitGTK with independent browser tabs, fail-closed tailnet routing, native favicon handling, managed downloads and session restoration. Fedora 44 CI covers normal-user sandboxed startup, directory/symlinked `/opt` layouts and restart/unlock behaviour.

The Linux AppImage needs an X11/XWayland desktop, `bubblewrap` and `xdg-dbus-proxy`. Run it as your normal user. If FUSE is unavailable, use `APPIMAGE_EXTRACT_AND_RUN=1 ./Womprat-0.4.5-x86_64.AppImage`. Linux browser password saving and native Wayland are not implemented. Live authenticated tailnet/exit-node browsing and recovery have not been independently verified here.

On 4 November 2026, Rui explicitly requested retagging this release to include the Linux implementation. `v0.4.5` moved from `534cd67` to `830bf7c`; the Windows assets were rebuilt and the AppImage was added. Existing downloads from the original release have different hashes. Use the current `SHA256SUMS.txt` for Windows and `LINUX-SHA256SUMS.txt` for Linux.
