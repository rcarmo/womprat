# Womprat v0.4.1

Fixes a crash that could occur when starting a managed download using browser cookies.

- Corrects ownership of the cookie list supplied by WebView2, preventing it from being released twice.
- Keeps asynchronous cookie callbacks alive until WebView2 releases them, including error paths.
- Rejects cookie retrieval when the browser is unavailable.

Download destinations, cookie-sharing rules and tailnet routing are unchanged. Windows ARM64 and Windows x64 binaries are available with SHA-256 checksums.
