# Womprat v0.4.4

Adds address-bar search, exit-node recovery and clearer navigation errors.

- Searches DuckDuckGo when address-bar input is not a URL. Choose DuckDuckGo, Bing or Google in **Settings → Browser → Address-bar search**; the choice is saved and takes effect immediately.
- Keeps URLs, domains, IP addresses and SSH/VNC/RDP addresses as direct navigation. Use `http://relay` or `relay/` for a single-label tailnet host.
- Verifies the effective exit-node selection and retries a saved selection if it could not be applied at startup. DNS diagnostics now show the routing error instead of treating a saved name as an active route.
- Shows Chromium network-error codes and native failure details in the navigation banner, with a **Copy error** button and wrapping text.

Public searches and internet browsing still require a working exit node. Certificate validation remains enabled, with the explicit session exceptions introduced in v0.4.3.

Windows ARM64 and Windows x64 binaries are available with SHA-256 checksums.
