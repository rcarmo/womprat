# Womprat v0.4.6

Fixes zoom shortcuts in browser tabs, terminals and Settings on Windows and Linux.

| Action | Browser tabs | Terminals |
| --- | --- | --- |
| Zoom in | `Ctrl++` or `Ctrl+=` | `Ctrl+Shift++` or `Ctrl+Shift+=` |
| Zoom out | `Ctrl+-` | `Ctrl+Shift+-` |
| Reset | `Ctrl+0` | `Ctrl+Shift+0` |

Browser shortcuts accept Shift and numeric-keypad variants and work with page or address-bar focus. Each native browser tab keeps its own zoom; reset returns to 100%. Terminal reset restores the configured font size, and ordinary Ctrl-only chords stay reserved for the remote shell. Focused Settings pages now handle zoom and reset too.

Linux also returns keyboard focus to the shell when hiding a native browser view, so terminal shortcuts reach the terminal. The README now puts Windows/Linux installation and first connection before technical details, with protocol behaviour in a separate usage guide.

Downloads include Windows ARM64, Windows x64 and a Linux x86-64 AppImage. Verify Windows downloads with `SHA256SUMS.txt` and Linux with `LINUX-SHA256SUMS.txt`.

The Linux AppImage needs X11/XWayland, `bubblewrap`, `xdg-dbus-proxy` and working user namespaces. Native Wayland, Linux ARM64 and Linux browser password saving are not implemented. Live authenticated Linux tailnet browsing and exit-node recovery have not been independently verified here. Network routing, sandboxing and certificate-consent requirements are unchanged.
